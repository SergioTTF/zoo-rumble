# Milestone 10 — Woodland arena and animal actions

The arena now has a detailed pixel woodland backdrop, with a quiet combat clearing and trees, rocks, brush, and mushrooms around its edge. Animals stand directly on this scenery: the raised platform, rim, and board shadow have been removed. The inverted orientation, 8×6 grid, eighteen preparation tiles, and yellow drop previews remain. Tile overlays appear only while dragging an animal or holding Tab, then disappear on release; blur and hiding the page also clear the held-key state.

All sixteen animals use dedicated four-pose idle, attack, and non-gory defeat sequences in four directions. Attacks include bites, paw and knuckle strikes, pecks, and wing/flipper actions. The approved sixteen walking frames are copied pixel-for-pixel into each new sheet; shop portraits remain unchanged.

Runtime sheets are `public/assets/animals/animated-v1/<animal>-sheet.png`, 512×2048 with 128-pixel frames. Frames 0–15 are walk, 16–31 idle, 32–47 attack, and 48–63 defeat. Each group contains left, front, rear, right rows, four poses per row. Foot baseline remains 120. Attack and defeat stop at the final pose; idle/walk loop. Defeat finishes with a short fade. Playback accelerates with battle speed, freezes while paused/hidden, and never controls simulation. Reduced motion uses a neutral idle or settled defeat frame.

Artwork was generated with the built-in image-generation tool using each approved animal sheet as a character/style reference. Exact generation prompts and original output paths are recorded in [action-generation.json](../scripts/action-generation.json). Originals remain in the generation directory and are copied unchanged into `public/assets/art-studies/actions-v1/`. The woodland original is `public/assets/art-studies/woodland-v1-original.png`; its nearest-neighbor 960×640 runtime copy is `public/assets/arena/woodland-v1.png`.

`scripts/prepare_action_animals.py` extracts rows using transparent gutters, normalizes isolated reversed side poses, applies one scale per animal, aligns feet, and asserts frame padding and unchanged walking pixels. Monkey and Gorilla supply three defeat poses; the last settled pose is held for the fourth frame. [Animation review](../public/assets/art-studies/actions-v1/animation-review.png) shows walk, idle, attack, defeat for the whole roster. [Preparation report](../public/assets/art-studies/actions-v1/preparation-report.json) records source rows, scales, frame counts, and output sizes.

Validation: all 77 tests pass, including dedicated action direction, loop, terminal frame, and reduced-motion selection. Type checking, linting, and production build pass. Browser review checks the woodland preparation view, combat completion, accelerated replay, pause, single-tick stepping, reduced motion, and dragging from the upper sprite area; console warnings/errors are absent. The existing Phaser bundle-size advisory remains.

These are short generated sequences, not bespoke hand-animated cycles: rear strikes are subtle and some poses change silhouette or apparent size. Further frame cleanup can follow visual playtesting. Milestone 11 remains release preparation.
