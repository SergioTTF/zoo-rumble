# Pixel-art references and asset shortlist

Researched September 16, 2026. Historical research only: the user clarified that the two supplied links are style references for creating original sprites, not a request to import packs. No external assets have been installed. The current original pixel sprites are documented in `ART_ASSETS.md`; the third-party candidates below are not the implementation plan.

## User references

- [Pixeline — Porcupine](https://pixeline-k.itch.io/pixel-art-creature-animal-porcupine): free/name-your-own-price 32×32 sheets, three-direction walking, needles folded or raised. The page declares no generative AI. The author explicitly permits commercial games in a comment and requests credit, but the page also says all rights reserved; retain the permission and confirm modification/distribution terms before importing edited assets. Reference for compact silhouettes and directional pixel animation. Porcupine is not currently a gameplay species.
- [Helm3t — Green Heart Farm Animals](https://helm3t.itch.io/green-heart-animal-pack): 16×16 top-down pixel style, multiple animations and four directions. Only the partial cow demo is free, and the demo is non-commercial. The full pack is currently $2.99 minimum and covers chicken/pig/cow/duck variants. Custom terms permit project use and editing but prohibit asset redistribution; metadata lists BY-ND, so clarify the applicable license before modifying. Use as a visual reference for now. The page declares no generative AI.
