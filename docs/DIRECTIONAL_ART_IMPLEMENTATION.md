# Complete directional animal pass

The user approved the Wolf/Fox/Dog/Gorilla visual direction and authorized autonomous generation, integration, and testing. Bear and Rabbit use the user-supplied sheets. Fourteen animal sheets use the built-in image-generation tool with the approved Wolf and user-supplied Bear/Bunny as style references. No animal definitions, progression, or balance changed.

## Preserved sources and preparation

All sources are in `public/assets/art-studies/`. Originals retain their RGBA transparency. `scripts/prepare_directional_animals.py` crops four columns and four rows, computes one scale per animal across all sixteen frames, uses nearest-neighbor resizing, centers each frame, and aligns its lowest visible pixels at a shared baseline. Species-specific maximum sizes keep smaller animals smaller. Runtime sheets are 512×512 with sixteen 128px frames, and portrait files use the first right-facing pose. The source Bunny's front-facing third slot in the left row is replaced in the prepared sheet by a mirror of the third right-facing pose. The source file remains unchanged.

Rebuild: `python scripts/prepare_directional_animals.py` (Pillow needed for authoring only). The preparation asserts visible content and transparent borders. `preparation-report.json` records source filenames, scales, frame sizes, and byte counts. The old pixel drawings and prototypes remain historical assets and are no longer runtime references.

## Playback and limitations

Rows are left/front/rear/right. `src/game/directionalAnimation.ts` selects the nearest facing from the screen-space vector and holds facing at rest. Isometric orthogonal steps usually select side rows; front/rear are selected when the vertical screen component dominates. Only walking frames are authored in these sheets. Idle and attack hold a contact frame; attacks, ability feedback, projectiles, hits, and deaths retain procedural effects. No claim of authored attack/death/flying cycles. Generated footfalls are approximate and may need an artist's cleanup after motion review.

Pause/hidden-page time freezes presentation, acceleration shortens action playback, reduced motion holds a contact frame, and simulation never depends on animation completion. React and Phaser share prepared artwork using Vite's base URL. `roster-runtime-preview.png` is the review contact sheet.

## Directional layout metadata

Preparation also writes `src/game/animalArtMetadata.json`. Each animal has a pixel-120 foot origin and individual star heights for left, front, rear, and right, computed from actual frame bounds at runtime display size. Changing direction updates star placement with the sprite row, avoiding excessive gaps above low side-view silhouettes.
